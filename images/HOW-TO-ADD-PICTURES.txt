HOW TO ADD YOUR PICTURES
========================
1. Put each photo in the folder shown below. Use .jpg, and keep the file name EXACTLY the same.
2. Refresh the page. The photo automatically replaces the colored name box.
   (If a file is missing, the site just shows the product name, so nothing breaks.)

TIPS
  - Photos around 800px wide are enough. Compress them (squoosh.app) so the site loads fast.
  - To use .png instead, change '.jpg' to '.png' in js/main.js and index.html.
  - To add a new product, add a line to the P list in js/main.js, then add its photo.
